2- in application properties [ HAM ]
	spring.kafka.consumer.key-deserializer=org.apache.kafka.common.serialization.StringDeserializer
	spring.kafka.consumer.value-deserializer=org.springframework.kafka.support.serializer.JsonDeserializer
	spring.kafka.consumer.properties.spring.json.use.type.headers=false
	spring.kafka.consumer.properties.spring.json.value.default.type=com.example.kafka_consumer.dto.Customer



## why use this to disable the Header of Message 
   if the producer send object customer class ( which this exist on pkg [ com.eg.dto ]
   so in conusmer app you create customer class ( which this exist on pkg [ app.com.dto ] )
   
   so whene the Kafla Listener try to receive this message and find the Header of message not same path or pkage
    it show error like this [  failed to resolve class name. Class not found [com.example.kafka.dto.Customer] ]	
   
spring.kafka.consumer.properties.spring.json.use.type.headers=false
